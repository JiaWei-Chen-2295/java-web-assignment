# ch10-cookie-auth 设计过程文档

## 1. 模块目标
实现一个基于 Cookie 的“5分钟免登录”系统，集成用户注册、登录验证、持久化认证（Cookie）以及欢迎展示页面。

## 2. 核心架构设计
- **技术栈**：Java 17, Jakarta Servlet 6.1, JSP, Maven。
- **数据管理**：使用 `MockDatabase` 在内存中模拟用户表（Map 结构），存储学号、姓名和密码。
- **拦截逻辑**：通过 `CookieAuthFilter` 对所有请求进行拦截，检测浏览器是否存在有效的 `user_id` 和 `user_name` Cookie。

## 3. 核心功能实现逻辑
1. **注册过程 (`RegisterServlet`)**：
   - 接收学号、姓名、密码。
   - 验证学号是否重复。
   - 注册成功后，立即发放有效期为 300 秒（5分钟）的 Cookie。
   - 重定向至 `welcome.jsp`。
2. **登录过程 (`SendCookieServlet`)**：
   - 匹配学号与密码。
   - 成功后发放 5 分钟有效期的 Cookie。
   - 将姓名进行 `URLEncoder` 编码以支持中文存储在 Cookie 中。
3. **免登录机制 (`CookieAuthFilter`)**：
   - 自动读取 Cookie 中的用户信息。
   - 若存在，则通过 `request.setAttribute` 将用户信息注入当前请求。
   - 若 Cookie 过期或不存在，页面逻辑（`welcome.jsp`）将重定向回登录页。

## 4. UI/UX 设计要点
- **色彩规范**：登录页使用靛蓝色 (`#4f46e5`) 强调专业感；注册页使用翡翠绿 (`#10b981`) 强调动作感；欢迎页使用现代卡片布局。
- **响应式布局**：使用 Flexbox 居中容器，适配移动端和桌面端。
- **用户反馈**：登录/注册失败时通过 Request Attribute 返回具体的错误提示（如“学号已存在”）。

## 5. 关键配置
- **Cookie 存储**：
  - `user_id`: 存储学号。
  - `user_name`: 存储姓名（URL编码）。
  - `Max-Age`: 300s。
